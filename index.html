Four ways to look at your disk

Every tab answers a different question. Together they turn "my disk is full" into a list of files you can act on.

Explorer

What is big?

The fastest way to find the giants. Greater walks the drive in parallel and streams results into a virtualized list while it is still scanning, so you never stare at an empty window.

  • Largest files first, with a size bar and a percentage of the largest file, so outliers stand out instantly.
  • Switch to By folder to see which directories carry the weight.
  • Handles 600,000 rows smoothly — the list only renders what is on screen.
  • Long paths, reparse points and permission-denied folders are handled without breaking the scan.
  • Per-row actions: file info, open in Explorer, move to Recycle Bin, delete permanently.
Clean

What is junk?

A rule engine that only ever proposes files from known scratch locations — temp folders, caches, logs, and download leftovers. It is deliberately narrow: if a path is not on the list, it is never suggested.

  • Two severities: safe (regenerated automatically) is preselected, optional (costs a re-download or rebuild) is opt-in.
  • Files modified recently are skipped as "probably in use", so nothing breaks a running program.
  • Results stream in live while the drive is still being walked.
  • Reason badges explain why each file was flagged, and filter chips split safe from optional.
  • Send to the Recycle Bin, or delete permanently when you are sure.
Duplicates

What is redundant?

Copies of the same file pile up quietly: "photo (1).jpg", the same installer downloaded three times, project folders backed up by hand. Greater finds them without reading every byte on the disk.

  • Groups by size first, then hashes only the candidates — so it stays fast on drives with millions of files.
  • Hardlink-aware: a hardlinked pair is not counted as reclaimable space.
  • Keeps one copy per group by oldest, newest or shortest path.
  • The last copy of a group can never be deleted, by construction.
  • Star any copy to override the keeper, group by group.
Statistics

What type of file eats the space?

One glance at the breakdown tells you whether the problem is video, images, archives, or a mountain of code and build output.

  • Every file bucketed into Images, Videos, Audio, Documents, Archives, Executables, Code or Other.
  • A stacked colour bar shows each category's share of the drive at a glance.
  • The legend lists size, percentage and file count per category.
  • Readouts for files scanned, elapsed time and the largest category.

Built to be safe by default

A cleaner that guesses is a cleaner that destroys things. Greater is built the other way round: it only offers what it can prove is disposable, and it always shows you the list first.

Whitelist, never blacklist

Junk rules match a fixed list of known scratch locations. A file that does not match is never proposed — there is no "probably junk" heuristic.

System files are hard-blocked

Page file, hibernation file, boot and BCD files, and System Volume Information are excluded before any rule runs. They cannot be selected, whatever the path looks like.

Nothing happens without a tick

Every delete starts from a visible list with checkboxes and a size total. Nothing runs on a timer, in the background, or on a guess.

Recycle Bin by default

The primary button is "Move to Recycle Bin". Permanent delete is a separate, clearly marked button with its own confirmation.

Live progress, real cancel

Bulk deletes run in a dialog that shows how many files are gone, which file is being deleted now, how much space is freed so far — and a Cancel button that actually stops within one batch.

Honest about failures

Files that cannot be removed are counted and reported, not silently skipped. Usually they are locked by a running program or owned by SYSTEM and need elevation.

Deleting is not the slow part any more

Two engines, chosen for the job. The shell is only used where it has to be.

Expect a Windows warning — here is why

The installer is not code-signed yet, so Windows has no publisher name to show and SmartScreen has no download history to go on. The message says unrecognized app, never threat detected. Two prompts can appear:

  • In the browser: the download is marked "isn't commonly downloaded" — open the downloads list (Ctrl+J) and choose Keep.
  • On launch: "Windows protected your PC" — click More info, then Run anyway.

You do not have to take that on trust. Compare the SHA-256 fingerprint of your file with the published one:

Get-FileHash .\Greater_1.0.0_x64-setup.exe -Algorithm SHA256

Expected fingerprint: 4A6D1C7E6552D6E3CBF955C816EF5AB088F67C866808A49C34D5AA7EA66B567F

The same hash ships with the release as SHA256SUMS.txt. A mismatch means the file was altered in transit — delete it and download again.

Questions people ask first

Will it delete my Windows files?

No. Junk rules only match a fixed whitelist of scratch locations (temp folders, caches, logs, download leftovers). Page file, hibernation file, boot and BCD files, and System Volume Information are blocked outright. On a real system drive, the 155,543 files Greater proposed were all inside temp and cache folders — and every one of them was shown in a list before anything happened.

Do I need to run it as administrator?

Scanning works fine without it. Installing needs administrator approval once because the app goes into Program Files for all users. Deleting files owned by SYSTEM (some Windows update leftovers, for example) needs elevation too — without it those specific files are reported as "could not be removed" and left alone.

Why were some files not deleted?

Two reasons, both shown in the progress dialog. Either the file is open in a running program (close it and try again), or it is owned by SYSTEM and needs an elevated run. Greater never forces a delete past a lock.

Can I undo a deletion?

Yes, if you used the Recycle Bin — restore from there as usual. Permanent delete is permanent; that is why it is a separate button with its own confirmation.

How can it scan a million files so fast?

Greater uses the Windows directory enumeration API directly from many threads at once, with large-buffer fetches, instead of asking the shell for one file at a time. It skips reparse points, keeps long paths intact, and streams results to the window while the walk is still running.

Does it send anything over the internet?

No. There is no telemetry, no analytics, no update check and no account. The app only talks to your own disk.

Which languages does the interface support?

English, French, Spanish, German and Arabic — including full right-to-left layout for Arabic. You can switch language at any time from the settings button.

Is it free?

Yes — download and use it at no cost, with no account and no nag screen.

Why does Windows warn me about this download?

Because the installer is not code-signed. A code-signing certificate costs a few hundred dollars a year, and this release was published without one — so Windows cannot show a verified publisher name, and SmartScreen has no download history to judge the file by. The result is a reputation warning ("unrecognized app"), never a virus detection. Instead of trusting it, you can verify it: the SHA-256 fingerprint published above belongs to the exact installer built and tested here. If your file produces the same fingerprint, it is byte-for-byte identical. If you would rather not click past a warning, do not install it — that is a reasonable choice.
